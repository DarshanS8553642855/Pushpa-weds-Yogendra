# Pushpa S & Yogendrachar M — Wedding Invitation

## 1. Add Your Media Files
Place your files inside `assets/` using these names (or update the paths in `index.html`):
- **Music:** `assets/audio/wedding-song.mp3`
- **Photos:** Add your photos in `assets/photos/` (e.g. `photo1.jpg`, `photo2.jpg`, ...) and list them in the `photos` array in `index.html`.
- **Videos:**
  - `assets/videos/engagement-1.mp4`
  - `assets/videos/engagement-2.mp4`
  - `assets/videos/save-the-date-1.mp4`
  - `assets/videos/save-the-date-2.mp4`
  - `assets/videos/save-the-date-3.mp4`

*(Keep each video under 100 MB for GitHub, or host larger videos on YouTube/Cloudinary and paste the URLs in `videoSlots`.)*

## 2. Push to GitHub
```bash
git init
git add .
git commit -m "Pushpa & Yogendrachar wedding invitation"
git branch -M main
git remote add origin https://github.com/DarshanS8553642855/pushpa-yogendrachar-wedding.git
git push -u origin main
```

## 3. Deploy on Vercel
Import the repository at https://vercel.com/new with **Framework Preset: Other** and click **Deploy**.
